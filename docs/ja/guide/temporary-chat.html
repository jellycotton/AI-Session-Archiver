ChatGPT・Gemini・Claude の一時チャットを保存する方法 — 閉じてしまった後も含めて

まだ閉じていない場合

無料でできる方法を、手軽な順に並べます。

1. 印刷機能で PDF にする

Ctrl + P を押して、送信先を「PDF に保存」にします。何も入れずに 済むのが利点です。ただし長い会話だと途中で切れたり、レイアウトが崩れたりします。 コードの部分は特に崩れやすいです。

2. 全部選択してコピーする

Ctrl + A → Ctrl + C で、メモ帳などに 貼ります。確実ですが、見出しやコードの体裁は失われます。

3. 保存用の拡張機能を入れる

Chrome ウェブストアで「ChatGPT エクスポート」などと探すと、PDF や Markdown で 書き出せるものがいくつも見つかります。無料のものが多く、普通の会話の保存なら これで十分です。

ひとつ注意点があります。選んだものが一時チャットで動くかどうかは、事前に 確かめてください。これらの多くは会話の履歴を読みに行く作りで、一時チャットは その履歴に残らないため、対象外になることがあります。

4. AI Session Archiver（ASA）で保存する

このページで紹介しているソフトです。一時チャットを最初から対象に入れて あります。入力欄のそばに出る保存ボタンを押すだけで、普通の会話と同じ手順で ファイルになります。

ここまでは無料版でできます。保存できる回数にも、使える期間にも制限は ありません（形式は HTML）。有料版にすると Markdown・テキスト・PDF でも出せます。

Windows 10 / 11 と Google Chrome が必要です。使うサービスに合わせて ChatGPT 版 / Claude 版 / Gemini 版から選びます。

ダウンロード - 無料版 ASA について

なお、この方法が使えるのはチャットの画面がまだ開いている間です。 閉じた後の話は次の節に分けて書きます。

閉じてしまった後

残念ですが、サービス側からは取り戻せません。

一時チャットは履歴に残らず、閉じたら開き直す方法がありません。ログインし直しても 出てきません。これは 3 サービスとも同じです。

救える可能性があるなら、それは自分のパソコンの中に残せている時だけです。

これに対処するために作ったのが AI Session Archiver（ASA） という Windows 用のソフトです。

使うための 2 段構え

  1. 設定でオートリカバリーをオンにする
  2. 残したいチャットでキャプチャモード（ウィジェットの ◉ ボタン） を開始する

キャプチャ中は、発言が届くたびに自分のパソコンの中のファイルへ 1 行ずつ書き足されます。 同時に、取得した件数が増えていくキャプチャ中の画面が出ます。

会話の途中から始めても間に合います。冒頭まで画面をスクロールすれば、それまでの やり取りもまとめて取得されます。

  • ブラウザのタブを閉じても、この画面は消えません。ブラウザではなく パソコン側の窓だからです。そこで「保存」を押せば、そこまでの会話がファイルに なります
  • その画面を × で閉じても、控えは残ります。次に ASA を 起動したときに、保存するか尋ねられます
  • 「キャンセル」を押すと控えは消えます。「これは要らない」という 意思表示として扱うためです
  • オートリカバリーは有料版（買い切り 1,480 円）の機能です。 無料版には入っていません
  • 既定ではオフです。一時チャットは履歴を残さないためのモードなので、 勝手に保存しないためです
  • キャプチャモードを開始していなかった会話は救えません。 どこにも控えが取られていないからです
  • ASA を入れる前に閉じた会話も、同じ理由で救えません

使い方

保存そのものの使い勝手は、無料版で確かめられます。期間の制限も、保存回数の 制限もありません。

  1. 配布ページから、使っているサービスの版をダウンロードします（ChatGPT / Gemini / Claude）
  2. zip を展開して、中の Setup_（サービス名）_ASA.vbs を実行します
  3. 画面の案内どおりに Chrome の拡張機能を追加します
  4. チャットの画面を開き直すと、入力欄のそばに小さな保存ボタンが出ます
  5. 閉じた後の救出まで使う場合は、設定でオートリカバリーをオンにし、残したいチャットで キャプチャモード（◉）を開始します

1〜4 は無料版でできます。5 は有料版が必要です。拡張機能は無料版と共通なので、 切り替えるときに入れ替えるのは本体だけです。

ASA にはオートリカバリー以外にも便利な機能があります。詳しくは下の「ASA について」から ご覧ください。

ダウンロード - 無料版 ASA について

有料版はオートリカバリーのほかに、Markdown・テキスト・PDF での保存、 チャットの種類ごとのフォルダ分け、ファイル名に使えるタグ 50 個（無料版は 3 個）が 付きます。買い切り 1,480 円で、月額料金はありません。
