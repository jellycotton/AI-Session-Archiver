Three things set it apart

Everything runs on your own machine. No conversation data is uploaded.

Auto-recovery

If a temporary or incognito chat is closed by an unexpected accident, its log is held temporarily on your device and can be saved the next time you start ASA. Auto-recovery is a setting you can freely switch on or off, so saving your logs and protecting your privacy are both possible.

Reusable tags

Register up to 50 tags once, then pick them at save time. They go into file names and titles, so a growing archive stays consistent instead of drifting into whatever each chat happened to be called.

A destination folder per format

HTML, Markdown, plain text and PDF each get their own destination - Markdown into an Obsidian vault, PDF into a work folder - so saved files land where you already work, with no moving afterwards.

What it looks like

A small widget on the chat page, and a settings window for everything else.
